# Décliner poses, orientations et expressions

## Décrire une pose sans changer le personnage

Séparer les paramètres :

- **Orientation du corps** : face, trois-quarts gauche/droite, profil, dos, trois-quarts dos.
- **Caméra** : hauteur du visage par défaut ; légère plongée/contre-plongée seulement si demandée.
- **Action** : verbe concret (saluer, pointer, réfléchir, voler, s'étirer…).
- **Regard** : vers le lecteur, vers une zone de l'interface, vers un accessoire.
- **Ailes** : ouvertes, demi-ouvertes ou repliées ; préciser ce qui est occulté.
- **Émotion et intensité** : calme, concentration, joie modérée, célébration…
- **Composition** : personnage entier ou buste, direction et espace nécessaire autour.

Employer « gauche de l'image » / « droite de l'image » pour l'emplacement, et « main gauche anatomique » si nécessaire. Ne pas laisser un changement de côté devenir une nouvelle morphologie. Un miroir n'est pas une preuve d'une nouvelle vue anatomique.

## Anatomie et perspective

La mascotte est stylisée avec deux bras, deux jambes, deux antennes et quatre ailes ; ne pas ajouter six pattes d'insecte réaliste. Les ailes partent du thorax derrière les bras. Les extrémités peuvent se masquer selon la perspective ; **quatre ailes anatomiques ne signifie pas quatre ailes entièrement visibles dans chaque pose**.

- **Face** : deux yeux visibles ; ailes réparties de part et d'autre ; conserver les différences supérieur/inférieur.
- **Trois-quarts** : référence principale pour les déclinaisons ; œil et ailes éloignés légèrement réduits/partiellement masqués, sans aplatir le visage.
- **Profil** : un œil principal visible ; autres traits partiellement occultés. Ne pas ajouter un deuxième œil flottant sur le contour du visage.
- **Dos** : pas de visage visible artificiellement à travers la tête ; antennes et motif d'ailes conservés avec une construction plausible. Le dos n'est pas documenté par la référence : le présenter comme proposition d'extension.
- **Ailes repliées** : chevauchement vertical naturel, motifs cohérents avec les ailes ouvertes. Ne pas transformer les ailes en cape indépendante.
- **Plongée/contre-plongée** : rester modéré si le contexte ne demande pas de raccourci fort ; éviter de cacher tous les marqueurs d'identité.

Un croquis de pose fourni par l'utilisateur guide uniquement les articulations et le cadrage. Le style, le visage, les couleurs et les ailes restent ceux de la référence officielle.

## Répertoire de départ

| Usage | Pose | Expression / garde-fou |
|---|---|---|
| Accueil | Vol stationnaire, ailes demi-ouvertes, main ouverte | Souriant, accueillant |
| Beaucoup de J | Léger élan vers l'avant, une main encourage | Déterminé, pas paniqué ni épuisé |
| Peu de J | Vol détendu ou petite pause | Confiant et calme |
| Rien de prévu | Bras relâchés, ailes au repos | Serein ; aucun triomphe de flamme non gagné |
| Révision en cours | Tête légèrement penchée, main près du menton | Concentré, sans grimace hostile |
| J terminé | Petit poing levé, ailes ouvertes | Joie proportionnée |
| Programme terminé | Petit bond/vol vers le haut, bras ouverts | Grande joie, pas de changement de proportions |
| Erreur / difficulté | Main tendue pour aider | Empathique ; pas de honte, pleurs ou moquerie |
| Indiquer une action | Un bras pointe vers la zone voulue | Regard dans la même direction |
| Chargement | Battement lent suggéré | Patient ; l'illustration n'affirme pas un vrai progrès réseau |
| Pause | Étirement léger ou repos | Fatigue douce possible, jamais culpabilisante |

Ces poses sont un vocabulaire de production, **pas des images ni des états métier validés**. Les critères réels de réussite ou de flamme restent ceux de l'app et des tickets associés.

## Expressions

Garder la structure du visage ; faire varier principalement sourcils, paupières, regard, bouche et inclinaison de tête. Les joues restent discrètes.

- Concentration : sourcils légèrement rapprochés, bouche petite ; ne pas reprendre l'air agressif des autres colonnes de la planche.
- Réussite : yeux en arcs ou grands yeux lumineux, bouche ouverte rose, antennes souples.
- Calme : sourire fermé léger, épaules et bras relâchés.
- Surprise : yeux plus ouverts sans dépasser la tête, petite bouche arrondie.
- Encouragement : regard dirigé vers le lecteur, sourire franc et main ouverte.

Éviter les expressions qui supposent une personnalité punitive ou infantilisante. Aucun attribut de genre n'est à amplifier.

## Séquences et animation

Si une animation est demandée : conserver cadrage, échelle de tête, implantation, motifs, palette et texture entre images ; les hachures ne doivent pas se renouveler aléatoirement à chaque frame. Privilégier l'animation de dessins/calques approuvés pour éviter le scintillement.

Pour une feuille de poses : même échelle, marges séparées, pas de membres d'une pose dans la voisine. Les vues de construction nouvelles doivent être approuvées avant de devenir des références secondaires. Une planche générée n'est ni un rig articulé ni un atlas prêt à intégrer sans contrôle.
