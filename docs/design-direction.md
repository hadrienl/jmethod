# Direction de design — J-Method

## Intention

Une application de révision pour des collégiens et lycéens : une page Aujourd’hui qui permet de savoir quoi faire, un vocabulaire concret et une progression sans pression. Cette direction constitue une hypothèse à tester auprès d’ados, pas une validation utilisateur.

## Références consultées

- [Student Productivity — Nodus Labs, Dribbble](https://dribbble.com/shots/27294754-Student-Productivity-App-UI-Design-Focus-Planner-Study-Dash) : palette lilas, organisation des tâches quotidiennes, espacement et simplicité. Retenir une action dominante et un espace calme.
- [Learning Progress Tracking — Keitoto, Dribbble](https://dribbble.com/shots/27160359-Learning-Progress-Tracking-Mobile-App-Study-Streak-Activity) : résumé de progression et activités regroupées. Retenir une progression fondée sur les données réelles ; ne pas reprendre de série fictive.
- [StudySpark, Behance](https://www.behance.net/gallery/243873199/StudySpark-Mobile-App-A-Smart-Student-Planner) : calendrier scolaire et plan de travail dans un même espace. Description consultable dans les résultats de recherche ; page complète bloquée par Behance (403).
- [StudySpace, Behance](https://www.behance.net/gallery/241828847/StudySpace-Student-Productivity) : cohérence entre web et mobile. Même limite de consultation que StudySpark.

Les références servent d’inspiration, sans reprise de leurs images ou assets.

## Application dans le prototype

- Fond clair, cartes blanches, violet pour les actions, vert citron pour l’action principale.
- Une prochaine séance mise en avant, les autres organisées par matière, le planning scolaire ensuite.
- Découvrir / S’entraîner / Se tester remplacent le jargon en première lecture. Les jalons J restent visibles.
- Progression calculée avec les séances terminées aujourd’hui et celles encore dues, y compris les retards.
- Pas de série de jours inventée, pas de message alarmiste sur les retards.
- Les boutons « Faire le point » ouvrent l’autoévaluation existante. Le prototype ne fournit pas encore d’exercices ou de quiz.
- Navigation avec état courant, lien d’évitement, focus visible, zoom mobile autorisé et animations réduites selon la préférence système.
- Aucune migration ou modification du format de stockage.

## Validation restante

Tester la compréhension auprès de 3 à 5 ados : identifier la prochaine action, ajouter un cours, comprendre les trois étapes et retrouver le planning. Un audit complet d’accessibilité (notamment les dialogues et les couleurs personnalisées) reste à faire.
